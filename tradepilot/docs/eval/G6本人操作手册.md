## 第一步：人工基线掐表（真人实做一遍，约 30–60 分钟）

打开 **PowerShell**（不是这个聊天窗口），逐条执行：

```powershell
cd D:\电商\tradepilot
$PY = D:\miniconda3\python.exe

# 先看当前状态（应是 null / 0/30）
& $PY scripts\human_baseline.py status

# 开始掐表（name 填你真实姓名，hourly 填你的实际时薪）
& $PY scripts\human_baseline.py timing --name "你的姓名" --hourly-cny 100
```

脚本会按 5 个阶段逐段计时，**每做完一阶段按一次回车**：

| 阶段 | 你要做的事（详见 `docs/eval/人工SOP.md`） |
|---|---|
| 1 市场扫描 | 当当/速卖通搜 dog bed，记 ≥8 条真实价格 + 网址，算最低/中位/最高 |
| 2 汇率折算 | 查 USD/CNY 汇率 + 时间，把三档价格折成美元 |
| 3 定价测算 | 按给定参数（头程$2.5/关税7%/尾程$5.5/佣金15%）手算到岸成本 + 20%净利报价下限 + 10/15/25% 三档 |
| 4 合规核查 | 速卖通规则 + Prop 65 + HTS 归类，各记来源网址 |
| 5 Listing 文案 | 英文标题≤200字符 + 卖点5条 + 简述，数字只用前四阶段数据 |

最后脚本问"写入？[y/N]"→ 输 `y`。自动写入基线并重算成本折算。

> 提示：计时中若被中断（Ctrl+C），脚本不会留半截假数据，重跑即可。
